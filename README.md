# collapsi-minimax-agent
Implementation of a Collapsi game AI using Minimax with Alpha-Beta pruning, multiple heuristics and benchmark evaluation.


# Collapsi IA — Algoritmo Minimax con Poda Alpha-Beta

Este proyecto implementa un **agente de Inteligencia Artificial** capaz de jugar el juego de tablero **Collapsi** utilizando el algoritmo **Minimax con poda Alpha-Beta** y funciones de **evaluación heurística**.

El sistema fue desarrollado como parte de un proyecto académico enfocado en **búsqueda adversarial, toma de decisiones inteligentes y análisis de rendimiento de algoritmos de IA**.

---

# Objetivo del Proyecto

El objetivo principal de este proyecto es analizar el comportamiento y el rendimiento de algoritmos de búsqueda adversarial aplicados a juegos estratégicos.

El agente de IA desarrollado:

- Evalúa posibles movimientos utilizando el algoritmo Minimax
- Reduce la complejidad del árbol de búsqueda mediante poda Alpha-Beta
- Utiliza diferentes funciones heurísticas para evaluar los estados del juego
- Analiza el rendimiento mediante pruebas de benchmark

---

# Técnicas de Inteligencia Artificial Implementadas

Este proyecto implementa los siguientes conceptos de IA:

- Algoritmo Minimax
- Poda Alpha-Beta
- Funciones de evaluación heurística
- Búsqueda con profundidad limitada
- Análisis de rendimiento (benchmark)
